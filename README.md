# KryazhevMA_vvs_2026
## Описание репозитория:  

**homework1 - Калькуляторы**  
Это простой калькулятор на Python. Чтобы показать эволюцию кода, одна и та же задача была решена четырьмя способами: от простого последовательного выполнения команд и разделения логики на отдельные функции до использования одной универсальной функции с циклом и реализации через класс.  
**homework2 - Работа со строками**  
Это интерактивная программа-игра для обучения базовой обработке текста в Python. На пяти уровнях пользователь шаг за шагом учится менять регистр букв, искать и заменять символы, а в финале работает с «умным» редактором. Этот редактор автоматически исправляет криво набранный текст, убирая лишние пробелы и правильно расставляя знаки препинания.  
**homework3 - Лабиринт**  
Это текстовая игра-лабиринт, в которой игрок ходит по комнатам, собирает предметы в инвентарь и пытается найти ключ и выход, сражаясь с монстрами и избегая ловушек. Карта открывается постепенно: игрок видит только те комнаты, где уже побывал, а остальные скрыты. У игрока есть здоровье и рюкзак, где можно хранить, сортировать, выбрасывать и применять предметы друг к другу, например, усилить меч зельем маны. Победа наступает, когда найден ключ и открыт выход, а по пути игра наглядно показывает, как правильно работать со списками предметов, чтобы изменения в копии не портили оригинал.
